# Personal FAQ

**Q: What is your primary development setup?**
A: I run a Windows desktop setup with an AMD Ryzen 5 5600 processor, an NVIDIA GeForce GTX 1070 GPU, and 16 GB of RAM. I do most of my coding in Cursor (my primary IDE, for its inline AI) and Visual Studio Code, using local Python virtual environments.

**Q: How do you handle AI models locally?**
A: I keep my models on a dedicated secondary drive (`D:\LLM_Models`). I deploy local open-source models, specifically Gemma 4, using LM Studio and Ollama connected via local OpenAI-compatible REST API endpoints.

**Q: What games do you play competitively?**
